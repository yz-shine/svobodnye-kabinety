# Свободные кабинеты

Сайт показывает, в какое время свободны кабинеты 408, 411, 412, 413, 415, 417, 419, 420, 424 и 427. Есть недельная таблица и вид по дням с шестью парами. Языки: русский, узбекский кириллицей и узбекский латиницей.

## Как выложить на GitHub

1. Создай новый репозиторий на github.com.
2. Загрузи в него все файлы из этой папки (Add file, Upload files). Нужны как минимум `index.html` и `data.js`.
3. Открой Settings, потом Pages. В разделе Branch выбери `main` и папку `/ (root)`, нажми Save.
4. Через минуту-две сайт откроется по адресу `https://твой-логин.github.io/название-репозитория/`.

Локально сайт тоже работает, достаточно открыть `index.html` в браузере.

## Чётные и нечётные недели

В начале `index.html` есть строка `EVEN_MONDAY`. Это понедельник чётной недели (сейчас 16.11.2026). От неё считаются все остальные недели, поэтому менять её нужно, только если чётность сбилась.

## Как обновить расписание

1. Сохрани страницы кабинетов из браузера (Ctrl+S, тип «Веб-страница, только HTML») в папку `source`, заменив старые файлы.
2. Запусти `python build_data.py` (нужен `pip install beautifulsoup4`). Файл `data.js` обновится.
3. Загрузи новый `data.js` на GitHub.

Расписание в LMS одно на чётные и нечётные недели сразу, поэтому одного сохранения хватает на обе. Замены и праздничные дни сайт не учитывает.
